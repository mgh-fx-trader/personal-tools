# Privacy Policy — rclone-personal

_Last updated: 2026-10-30_

This application (**rclone-personal**) is a Google OAuth client registered by and for the repository owner's personal use only. It is used solely with [rclone](https://rclone.org/) to upload and download the owner's own backup files.

- It accesses only files it creates in the owner's Google Drive (`drive.file` scope).
- It does not collect, store, or share any user data.
- It is not offered to, and cannot be used by, anyone other than the owner.
- No data is transmitted to any third party; files move only between the owner's computer and the owner's Google Drive.

Questions: open an issue in this repository.
